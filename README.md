# 🤖 n8n Telegram AI Agent

This project is an n8n workflow that creates a Telegram bot with AI capabilities.

## 🔹 Features

* Receive messages from Telegram
* Handle voice messages
* Transcribe audio to text
* Process text using AI (Google Gemini)
* Send responses back to the user

## 🛠️ Tools Used

* n8n
* Telegram Bot API
* Google Gemini AI

## ⚠️ Notes

* Credentials (API keys, tokens) are not included
* You need to configure your own credentials in n8n

## 🚀 How to use

1. Import the JSON file into n8n
2. Connect your credentials
3. Activate the workflow
